# 方法论

## 概述

综合信号分析从四个维度评估投资标的，每个维度收集支持性证据和反对性证据，最终形成结构化信号输出。

## 四个维度

### 1. 价格维度 (price)

基于行情数据，分析价格走势、成交量变化、技术指标。

- 支持性证据：放量上涨、均线多头排列、突破关键阻力位
- 反对性证据：缩量上涨、高位放量滞涨、技术指标顶背离

### 2. 资金维度 (capital)

基于资金流向数据，分析主力资金、北向资金、融资融券等动向。

- 支持性证据：主力资金净流入、北向资金加仓、融资余额增加
- 反对性证据：主力资金净流出、北向资金减仓、融资余额下降

### 3. 情绪维度 (sentiment)

基于博主观点、市场情绪数据，分析市场参与者情绪。

- 支持性证据：博主积极看多、情绪指数处于低位回升、讨论热度上升
- 反对性证据：博主普遍看空、情绪指数处于高位、恐慌指数上升

### 4. 事件维度 (event)

基于新闻、公告等数据，分析可能影响股价的事件。

- 支持性证据：政策利好、业绩预增、行业催化剂
- 反对性证据：监管风险、业绩不及预期、利空传闻

## 置信度评估

- **high**：coverage_rate >= 0.75（至少 3 个维度有数据）
- **medium**：0.50 <= coverage_rate < 0.75（2 个维度有数据）
- **low**：coverage_rate < 0.50（仅 1 个维度有数据）

## 约束

- 不输出强烈买入建议
- 不给个性化仓位
- 不承诺收益
- 失效条件必须列出
